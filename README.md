# Fit'Art - website

Static website for **Palestra Fit'Art (Fit'Art ASD)** - gym and art gallery in
Rosate (MI), Italy. Built with [Astro](https://astro.build) 7, deployed to
GitHub Pages: **https://murphy-afk.github.io/fit-art/**

## Quick start

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
node check-style.cjs
```
